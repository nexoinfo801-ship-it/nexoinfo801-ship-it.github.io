Aviso de privacidade

Site institucional NEXO ERP PDV · Última atualização: 25 de outubro de 2026

Este aviso explica, de forma resumida, como funciona o tratamento de informações quando você navega pelo site institucional do NEXO ERP PDV. Ele se refere a esta página pública e não substitui os termos, contratos ou avisos de privacidade de outros serviços.

Em resumo: o formulário comercial e o chat demonstrativo funcionam no seu navegador. O site prepara uma mensagem para você revisar; ele não possui, neste momento, um formulário conectado a um banco de dados próprio para armazenar os campos enviados.

1. Informações digitadas no formulário

Se você preencher o formulário comercial, os campos são usados pelo código da página para preparar uma mensagem com o contexto do seu negócio. Ao selecionar “Continuar pelo WhatsApp”, o navegador tenta abrir o WhatsApp com essa mensagem preenchida. Você pode revisar o conteúdo antes de enviá-lo. O site não envia esses campos a um servidor próprio nem os grava em uma base de leads por meio desse formulário.

2. Cleópatra demonstrativa

A Cleópatra desta página usa respostas programadas e não consulta o sistema NEXO real. As mensagens digitadas são processadas pelo código executado no navegador para selecionar uma resposta. Quando você escolhe falar com a equipe, a pergunta pode ser incluída na mensagem preparada para o WhatsApp. Evite inserir senhas, dados bancários, documentos pessoais ou informações comerciais confidenciais no chat.

3. WhatsApp e serviços de terceiros

O WhatsApp é um serviço externo. Se você abrir o link e enviar uma mensagem, o tratamento das informações também estará sujeito às políticas e práticas da Meta/WhatsApp. O site não controla como o serviço externo processa os dados depois que você sai desta página. Outros links externos abrem os respectivos sites, que têm seus próprios avisos e práticas.

4. Hospedagem e dados técnicos de navegação

O site está hospedado no GitHub Pages. A infraestrutura de hospedagem pode processar dados técnicos de acesso, como endereço IP, horário da requisição, navegador e informações necessárias à segurança e operação do serviço, conforme as práticas do provedor. Este site não implementa, no código da página, cadastro de usuários, analytics próprio ou armazenamento dos campos do formulário em banco de dados.

5. Finalidade e minimização

As informações que você decide enviar à equipe são utilizadas para entender seu contato e responder à solicitação comercial. Informe apenas o necessário para essa finalidade. Não envie dados sensíveis nem dados pessoais de terceiros sem autorização e necessidade legítima.

6. Segurança e limites deste aviso

Não transmita informações confidenciais pelo chat demonstrativo. Embora a página use HTTPS quando acessada pelo endereço oficial, isso não elimina todos os riscos da internet nem define, por si só, como serviços externos tratam os dados. Este aviso descreve o funcionamento conhecido do site; não constitui garantia técnica de segurança de terceiros nem parecer jurídico.
